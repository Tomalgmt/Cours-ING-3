Ici on ajoute nftables avec sudo apt install nftables pour avoir un pare feu

Je veux modifier le fichier /etc/nftables.conf pour ajouter une politique restrictive par defaut en entrée et sortie.
Je comence par faire un .back (J'ai fais la meme chose sur certains fichiers de configuration avant).

Et on le modifie comme suit : 


```typescript
#!/usr/sbin/nft -f

flush ruleset   # ça sert a vider les règles existantes avant d'ajouter les nouvelles 

table inet filter {
    chain input {
        type filter hook input priority filter; policy drop;

        iifname "lo" accept                   # permet d'accepter les input qui viennent de l'interface loopback (localhost)
        ct state established,related accept   # permet d'accepter les input qui sont liés à une connexion déjà établie (exemple : si on a une connexion ssh ouverte, les paquets de cette connexion seront acceptés)
        ct state invalid drop                 # permet de drop les input qui sont invalides (exemple : si on a un paquet qui ne correspond à aucune connexion existante)

        ip protocol icmp accept               # permet d'accepter les input qui sont des paquets ICMP (exemple : ping)
        ip6 nexthdr icmpv6 accept             # permet d'accepter les input qui sont des paquets ICMPv6 (exemple : ping6)

        tcp dport 22 accept                   # permet d'accepter les input qui sont des paquets TCP destinés au port 22 (exemple : ssh)
        tcp dport 8080 accept                 # permet d'accepter les input qui sont des paquets TCP destinés au port 8080 (exemple : service web)
    }

    chain forward {
        type filter hook forward priority filter; policy drop;  # policy drop dans chain forward permet de drop tous les paquets qui sont destinés à être forwardés (exemple : si on a un routeur qui reçoit des paquets destinés à un autre hôte, ces paquets seront dropés)
    }

    chain output {
        type filter hook output priority filter; policy accept; # policy accept dans chain output permet d'accepter tous les paquets qui sont destinés à être envoyés (exemple : si on a un service qui envoie des paquets, ces paquets seront acceptés)
    }
}
```

Après ça on charge les règles :

On peut aussi check les paramètres qu'on a ajouté avec :

K. MISES A JOUR
  [PASS] Aucune mise a jour de securite en attente
  [FAIL] Mises a jour automatiques configurees

Les mises à jour automatiques sont les dernieres etapes du durcissement, pour empecher des logiciels obsoletes d'etre installés et de rendre le systeme vulnérable.

Il existe un package "unattended-upgrades" qui permet de configurer les mises à jour automatiques sur un système Debian/Ubuntu.
On va l'installer avec :
```
sudo apt install -y unattended-upgrades
```

Et on va le configurer avec un fichier de configuration :
```
sudo vim /etc/apt/apt.conf.d/20auto-upgrades
```

Dans lequel on écrit :
```
APT::Periodic::Update-Package-Lists "1";      # permet de mettre à jour la liste des paquets disponibles tous les jours
APT::Periodic::Unattended-Upgrade "1";        # permet d'installer automatiquement les mises à jour de sécurité tous les jours (les mises à jour autorisées de unattended-upgrades)
APT::Periodic::AutocleanInterval "7";         # permet de nettoyer automatiquement le cache des paquets tous les 7 jours
```

Enfin on active le minuteur apt pour que les mises à jour automatiques soient réellement activées avec :
```
sudo systemctl enable --now apt-daily.timer
sudo systemctl enable --now apt-daily-upgrade.timer
```

Pour check la configuration : 
```
